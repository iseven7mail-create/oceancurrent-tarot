# 洋流與你同在｜在乎你的暖陽

**[直接開始互動](https://iseven7mail-create.github.io/oceancurrent-tarot/)** · [原網站](https://oceancurrent-tarot-companion.i-seven7mail.chatgpt.site/)

78 張洋流塔羅牌的繁體中文互動陪伴遊戲。以原始牌面的橘白分區、粗黑線條、復古紙感、薄荷綠與粉紅色延伸全站設計。

## 可以玩什麼

- 「簡單的提醒」抽一張；「多點陪伴」抽三張不重複的牌，支援正逆位與逐張翻牌。
- 完整 78 張牌意、陪伴文字、鼓勵、專屬小練習與三選一自我探索。
- 78種暖流圖鑑、分類搜尋、收藏與練習進度。
- 五題牌意小挑戰，逐題提供解說。
- 個人心情手帳，逐則製作 1080 × 1350 PNG 分享卡；長文自動分頁。
- 每則心情與分享卡包含「@沈伯洋，你永遠是我們的暖陽。」。
- 手機、桌面、鍵盤操作與減少動態效果設定。

## 開啟網站

點上方「直接開始互動」，不用安裝或下載程式。GitHub 專案頁顯示原始碼；GitHub Pages 網址則是可以直接玩的網站。

也可下載這個儲存庫，開啟 `index.html`，或使用任意靜態網站伺服器預覽。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 網站入口與導覽 |
| `app.js` | 抽牌、圖鑑、牌意挑戰、收藏與手帳 |
| `cards.js` | 78 張牌的正逆位、陪伴與練習內容 |
| `journal-cards.js` | 在使用者裝置製作 PNG 分享卡 |
| `style.css`、`journal.css`、`deck-theme.css` | 排版與牌卡風格 |
| `assets/` | 78 張牌面、牌背與對應縮圖，共 158 張 WebP |
| `asset-manifest.json` | 網頁牌卡與來源 PNG 檔名對應 |

沒有後端伺服器或資料庫。心情手帳、草稿、收藏及進度只保存在使用者自己的瀏覽器，不會隨原始碼上傳。不同網址或裝置的紀錄不會自動同步。

本作為非官方支持者創作，未代述沈伯洋本人言論。牌意以偉特史密斯傳統主題為基礎，陪伴與反思文字為本作詮釋。

## 維護與發布

GitHub Pages 來源設為 `main` 分支的根目錄。更新這些檔案並提交後，GitHub 會重新發布互動頁面。`.nojekyll` 讓網站直接以靜態檔案提供服務。

本機可執行 `node verify.cjs`，檢查 78 張牌、素材、網站資源與程式語法。
